## Texto pronto para descrição

O Estuda+ é um aplicativo móvel Android/iOS para organizar tarefas acadêmicas e leituras. Desenvolvido em React Native com Expo e TypeScript, oferece cadastro/login local, oito telas com navegação, CRUD completo de tarefas em SQLite, dashboard de progresso, consulta à API Open Library com cache offline e exportação JSON pelo sistema de arquivos e compartilhamento nativo. A documentação inclui proposta, wireframes, protótipo navegável, arquitetura, mapeamento de requisitos, testes e roteiro de apresentação. O projeto usa PBKDF2-SHA256 para senhas e SecureStore para sessão. A conta é local, sem sincronização ou recuperação de senha.

# Estuda+

Aplicativo de produtividade estudantil para Android e iOS, desenvolvido por **Gustavo Gouveia** para a FAFIRE com React Native, Expo e TypeScript.

Login local, tarefas com CRUD e uso offline em SQLite, consulta de livros na Open Library e exportação JSON. As contas ficam no aparelho, sem sincronização.

Para executar com Expo Go compatível com SDK 57:

```powershell
npm.cmd ci
npm.cmd start
```

Leia o QR code no celular. Para validar: `npm.cmd run check`.
